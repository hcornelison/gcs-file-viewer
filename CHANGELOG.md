# Changelog

Notable changes to GCS File Viewer. The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and versions follow [Semantic Versioning](https://semver.org/).

## Unreleased

First public version.

### Added

- Browse the buckets of a Google Cloud project, or open any bucket by name, including public buckets without signing in.
- Sign in with a service account key file, Application Default Credentials or the gcloud CLI's login.
- Folder-style browsing with back, forward, up, breadcrumbs, paged loading of large folders, filtering and search.
- Upload and download of files and whole folders, with progress and cancelling.
- Create folders, rename, copy, move and delete, by menu, keyboard, clipboard or drag and drop.
- Details pane with object properties, text and image preview, and editing of content type and Cache-Control.
- Folder size calculation.
- A running estimate of what the session has cost in Cloud Storage charges.
- Light and dark mode.
- Packages for Windows, macOS and Linux, built by a release workflow with checksums and build provenance.
