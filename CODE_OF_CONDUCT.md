# Code of conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful and constructive, assume good intent, and keep discussion about the work. Harassment, personal attacks and discriminatory language are not acceptable in issues, pull requests or any other project space.

## Reporting

If someone's behaviour in this project is a problem, contact the maintainer, [@hcornelison](https://github.com/hcornelison), or use GitHub's [report abuse](https://docs.github.com/en/communities/maintaining-your-safety-on-github/reporting-abuse-or-spam) tools on the content itself. Reports are handled privately.

The maintainer may edit or remove comments, commits, issues and other contributions that break this code of conduct, and may block repeat offenders from the project.
